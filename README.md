# AI Voice Clone Detector

A desktop application that analyzes audio files and determines whether they contain real human speech or AI-generated (synthetic/cloned) voice — with plain-English reasoning for each prediction.

## Overview

This project detects AI voice cloning and speech synthesis by combining a pretrained speech representation model (Wav2Vec2) with a custom-trained classifier. It was trained and evaluated on ASVspoof 2019, a standard academic benchmark for anti-spoofing research.

## Results

- **Equal Error Rate (EER): 6.08%** on the ASVspoof 2019 LA dev set
- For reference: 0% = perfect detection, 50% = random guessing
- Trained on 25,380 labeled audio samples (real + AI-generated across 6 synthesis methods)

## How it works

1. **Audio preprocessing** — converts input audio to mono, resamples to 16kHz, normalizes length
2. **Feature extraction** — uses Meta AI's pretrained Wav2Vec2-base model to convert raw audio into a 768-dimensional embedding
3. **Classification** — a custom-trained 2-layer neural network classifies the embedding as real or AI-generated
4. **Reasoning generation** — extracts interpretable acoustic features (pitch stability, spectral flatness, zero-crossing rate, silence patterns, spectral bandwidth) and generates a plain-English explanation based on which signals are most unusual

## Tech stack

- **Python**
- **PyTorch** + **Wav2Vec2** (via Hugging Face Transformers)
- **Librosa** for audio feature extraction
- **Tkinter** for the desktop GUI

## Dataset

[ASVspoof 2019 Logical Access (LA)](https://datashare.ed.ac.uk/handle/10283/3336) — a widely used academic benchmark dataset for spoofing/anti-spoofing research, containing bonafide (real) speech and spoofed speech generated by multiple text-to-speech and voice conversion systems.

## Setup

```bash
pip install torch torchaudio transformers librosa soundfile numpy
python app.py
```

Then click "Select Audio File" and choose a `.wav`, `.flac`, `.mp3`, or `.ogg` file.

## Known limitations

- Trained exclusively on studio-quality ASVspoof recordings — accuracy drops significantly on real-world audio recorded with different microphones/environments, a known challenge in this field called the **domain generalization gap**
- Not yet tested against newer (post-2023) AI voice generation tools not represented in the training data
- English speech only

## Future improvements

- Fine-tune the feature extractor end-to-end rather than using it frozen
- Train on more diverse, real-world audio conditions to close the generalization gap
- Test on newer datasets (WaveFake, In-the-Wild) with unseen attack types
- Add support for real-time microphone input
